1. City Column --> Customer Table

we have 20,000 rows in this table , 100s of rows have random 5-6 line long strings which are reviews written by users in city section we dont need ..
most city names are very short w.r.t string length ..

so we have remove long strings setting a [threshold of length] in this table by filtering current city table and [threshold of words]

------------Code ---------

FilterCity = 
VAR CurrentValue = Customers[City]

VAR TotalCharacters = LEN(CurrentValue)
VAR TotalWords  = LEN(CurrentValue) - LEN(SUBSTITUTE(CurrentValue, " ", "")) + 1  //substituting spaces with null 
//number of spaces between words + 1 = total words

VAR IsTooLong = TotalCharacters > 30
VAR TooManyWords = TotalWords > 4
VAR IsReviewText = CONTAINSSTRING(CurrentValue, "RATED")

RETURN
IF(
    // If ANY of these are TRUE...
    TooManyWords || IsTooLong || IsReviewText, 
    
    // ...then give me a blank
    BLANK(), 
    
    // ...otherwise, give me the original city name
    CurrentValue
)
